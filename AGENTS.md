# Instruções do Projeto

- **Estabilidade do Código**: Apenas realize alterações no código do site (HTML, CSS, React) quando houver um pedido explícito de mudança visual ou funcional. 
- **Dúvidas e Consultas**: Ao responder dúvidas externas, explicar processos ou gerenciar arquivos, não faça edições automáticas no código fonte (`src/App.tsx`, etc) para manter a estabilidade da versão atual.
